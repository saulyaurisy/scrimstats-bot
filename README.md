# 🏆 ScrimStats Bot

### Free Fire Scrim Management for Discord

ScrimStats Bot is a Discord bot designed to simplify the management of **Free Fire scrims and competitive matches**.

The bot allows moderators to create training sessions, receive match logs and process match information directly through Discord.

> ⚡ Fast • 🎯 Organized • 🤖 Automated

---

## 🎮 What is ScrimStats?

ScrimStats was created to automate repetitive tasks during Free Fire scrims.

Instead of manually processing every match, moderators can upload the generated `.log` file to Discord and let the bot process the match information automatically.

### Main Features

- 🏆 Training management
- 📄 Automatic `.log` detection
- 🔎 Match log processing
- 👥 Team and player information
- 💀 Kill tracking
- 📊 Match statistics
- 🤖 Discord automation
- 🌐 Multi-server support

## 🤖 Commands

| Command | Description |
|---|---|
| `/ping` | Checks if the bot is online |
| `/training-create` | Creates a new training |
| `/training-end` | Ends the active training |

## 📄 Match Logs

After a match, the generated `.log` file can be uploaded directly to the training channel.

```text
Discord
   │
   ▼
📄 Match Log
   │
   ▼
🔎 Log Parser
   │
   ▼
📊 Match Data
   │
   ▼
🏆 Training Results
This allows moderators to process matches faster and reduce manual work.

---

## 🌐 Multi-Server

ScrimStats Bot is designed to work across multiple Discord servers.

The bot uses **global Discord slash commands**, allowing the same application to be installed and used by different communities without requiring a separate bot for each server.

Each Discord server can use the bot independently for its own scrim management.
